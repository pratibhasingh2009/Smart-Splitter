Abstract

Managing personal monthly expenses alongside shared group expenditures has become a recurring challenge in college life, shared student accommodation, and team outings. Traditional methods like paper notes, chat messages, or spreadsheets suffer from calculation errors, confusing pairwise debts, and lack of instant payment settlement.

This project presents Personal Budget & Expense Splitter (SmartSplit), a responsive, full-stack web application designed and built by Group 7 (2nd Year, B.Tech CSE) using React 19, TypeScript, Vite, Tailwind CSS, and Firebase Firestore. The application integrates personal budget analytics with multi-party group bill splitting.

The key algorithmic innovation of this system is the Greedy Net-Balance Debt Simplification Algorithm. For $N$ members in a group, unorganized splitting results in up to $N(N-1)/2$ complex transfers. SmartSplit computes the net algebraic balance for each participant and uses a greedy dual-pointer matching mechanism that reduces the total number of transactions to at most $(N - 1)$, eliminating cyclic payment loops completely.

Furthermore, the system incorporates equal, exact, and percentage split modes, multiple currency support, dynamic UPI QR code generation for instant payment via PhonePe, Google Pay, and Paytm, and real-time cloud data persistence. Performance benchmarks verify that client-side settlement computations run in under 2 milliseconds, providing a seamless financial tool for modern shared living.

Keywords: FinTech, Debt Simplification, Greedy Algorithm, React 19, TypeScript, UPI QR Integration, Firebase Firestore.

System Design & Mathematical Methodology

4.1 Greedy Debt Simplification Algorithm

In an unoptimized group settlement with $N$ participants, the number of distinct directed peer-to-peer debts can grow up to $N(N - 1)/2 \in O(N^2)$. SmartSplit optimizes this to at most $(N-1)$ transactions using a greedy two-pointer matching process:

// Algorithmic Implementation in SmartSplit Engine

1. Compute Net Balance for each member: Balance(u) = TotalPaid(u) - TotalLiability(u)

2. Partition members into Debtors (Balance < 0) and Creditors (Balance > 0)

3. Sort Debtors descending by debt magnitude; Sort Creditors descending by credit magnitude

4. WHILE debtors.length > 0 AND creditors.length > 0:

    TransferAmt = MIN(debtor.amount, creditor.amount)

    Record Transaction: [Debtor] pays TransferAmt to [Creditor]

    Update remaining balances; Advance index if balance reaches 0

Chapter 5

Implementation & Key Feature Modules

5.1 Personal Budget & Dashboard Module

The dashboard centralizes individual and group finances with real-time cards (Total Spending, You Are Owed, You Owe, Net Balance) and category visual distributions.

5.2 Multi-Modal Expense Splitting Engine

The modal (AddExpenseModal.tsx) enables: Equally ($1/N$), Exact Rupee Amounts, Percentages (%), and Itemized Dish/Price Breakdown.

5.3 Live Camera Receipt Scanner (HTML5 MediaDevices)

Directly interfaces with browser hardware using navigator.mediaDevices.getUserMedia. Renders live camera view in a <video> element, captures snapshots via <canvas>, and saves base64 JPEG receipts without third-party server costs.

5.4 Real-time Group Chat Module (`GroupChatView.tsx`)

Integrated messaging channel powered by Firestore real-time listeners (onSnapshot). Members can discuss expenses, attach captured bill photos, and share documents with zero delay.

5.5 Dynamic UPI Intent & QR Code Generator

Generates standard NPCI UPI links (upi://pay?pa=...&am=...) and high-contrast QR codes directly on-screen for 1-tap PhonePe, Google Pay, and Paytm settlements.

5.6 Zero-Dependency Presentation Mode

Provides standalone frontend-demo.html which functions fully upon double-clicking in any browser without needing node servers or command line execution.
